# Sarvam-Native — portfolio site

Static site for two Sarvam-native AI projects:

- **Setu** (`/setu`) — open-source MCP server for Sarvam's API, with an interactive tool explorer + install/usage docs.
- **Vaani** (`/vaani`) — real-time code-mixed voice agent for BFSI (demo).

Pure HTML/CSS/JS, no build step. Deployed on Netlify from this repo — every push to `main` auto-updates the live site.

## Local preview

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
